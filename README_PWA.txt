מדריך למטייל — גרסת PWA להתקנה

קבצים בתיקייה:
  index.html              האפליקציה (פתחו קובץ זה)
  manifest.webmanifest    הגדרות התקנה
  sw.js                   Service Worker (עבודה חלקית ללא רשת)
  icon-192.png / icon-512.png / apple-touch-icon.png
  Travel_Guide.html       עותק זהה (גיבוי/שיתוף)

איך להתקין בטלפון:

1) העלו את כל התיקייה לשרת HTTPS (Netlify, GitHub Pages, Firebase וכו')
   — PWA דורש HTTPS (או localhost).

2) פתחו את האתר בכרום / ספארי בטלפון.

3) אנדרואיד (Chrome):
   תפריט ⋮ → "הוסף למסך הבית" / "התקן אפליקציה"

4) אייפון (Safari):
   כפתור שיתוף □↑ → "הוסף למסך הבית"

שימוש מקומי לבדיקה (מחשב):
  בתיקייה הזו הריצו:
    python3 -m http.server 8080
  ואז בדפדפן: http://localhost:8080

הערות:
- נתונים חיים (מזג אוויר, שער, תמונות, מפות) דורשים אינטרנט.
- ערים ומסלולים שנשמרו נשמרים במכשיר (localStorage).
- יוצר: יעקב זוהר
